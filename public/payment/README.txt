Official payment logos (optional)
---------------------------------
The checkout draws its own simple logo badges. To use an official logo instead,
drop an SVG into this folder with the matching name and it is picked up automatically:

  card.svg   apple-pay.svg   google-pay.svg   cash-app.svg   zelle.svg   paypal.svg   paystack.svg

Download the official files from each brand's own brand or press page and follow their usage rules.
Remove a file and the drawn badge comes back.
